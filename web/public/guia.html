01 / FIRST STEPS

Start here, even without your pedal

  1. Open the editor in your browser. A computer with Chrome or Edge is the easiest starting point for folder access and MIDI.
  2. Open a backup with Open folder, Import folder or Import ZIP. In local development, Demo fixtures loads example memories for practice. This guide uses those example settings in its screenshots.
  3. Click Memory, choose a memory on the left, then open Loop → Tracks.
  4. Choose Track 1 through Track 6. Adjust the segmented Play Level or Pan control, or click a state card to see how editing works.
  5. Click the small information button beside a parameter for its explanation. Use Discard memory to undo unsaved changes in that memory.
Before working with your own loopsCopy the entire ROLAND folder from the pedal to a safe place on your computer. Keep that original backup separate from the folder you edit. Demo fixtures contain example settings, not your recordings.

02 / OPEN YOUR FILES

Choose how you want to edit

Open folder

Choose the ROLAND folder on the pedal or an editable backup on your computer. Grant write access when asked. Saving updates the files in that selected folder.

Import folder / Import ZIP

Load a copy for editing without direct write access to the original folder. After saving your edits, use Export ZIP to download the result and transfer it to the pedal.

Connect the pedal for file editing

  1. Connect the RC-600 to your computer with a USB cable.
  2. On the pedal, open MENU → USB and enable STORAGE. Wait for the RC-600 drive to appear.
  3. Copy the complete ROLAND folder to your computer as a backup.
  4. In the editor, click Open folder and select ROLAND. The DATA folder alone can load settings, but choose ROLAND when you also need WAVE audio.
  5. Click Backup done — unlock save once the backup is safe.

Connect to USB opens these instructions. It cannot enable Storage on the pedal for you. USB Storage is for files; live MIDI is a separate connection mode.

Find your way around

System
Edit shared pedal settings, including USB, MIDI and setup. Save these separately with Save system.
Play Drum
Play and loop drum notes through MIDI, with kits, presets and pad settings.
Setlists
Organize songs for performance, open charts and scores, and configure MIDI actions.
Tuner
Tune from an audio input connected to the browser.
3D Model
Explore a visual RC-600 model with rotation, zoom, panel and rear views. This view helps you recognize the hardware; it does not control the pedal.
Chain
Show a visual map of inputs, effects, tracks, rhythm and outputs. Click a block to open its related controls; the small toggle changes its on/off state. Use +, − and Fit to adjust the view.

EDIT WITH THE NEW LAYOUT

Read the setting. Touch the control. See the change.

The same gestures appear throughout Memory and System. The breadcrumb above the workspace shows your current path, such as Memory → Loop → Tracks → Track 1. Use an earlier level to return to its tabs; you keep the edits you have made.

Click cards

A card combines the parameter name, an icon and its current value. Click it to switch states or step through several choices. Direction switches Forward / Reverse; Stop Mode cycles Immediate / Fade / Loop End. Read the value as well as its color.

Scrub cards

For a numeric card, use the mouse wheel, drag sideways on a touch screen or click the two arrows. Measure also has Auto and Free modes; click its numeric value to return to Auto. Open the information icon for the meaning and range of a setting.

Segmented sliders

Play Level, Pan and many effect levels display their position as bars. Drag to set the value. Use the small reset button beside the readout when available. Track Play Level resets to 100; Pan resets to Center.

Faders and selectors

EQ uses vertical faders: drag, scroll or use arrow keys; double-click a fader to reset it. Function selectors open a searchable list. Dedicated effect editors add pictures, musical-note controls and graphs appropriate to the effect.

Color is a reading aid. Grey can indicate Off or a bypassed control; other colors distinguish states or values. A highlighted card is not necessarily an error. Always read its label and information button. Above-default volume settings can reach orange and red.

Try a track edit in three passes

  1. Set Play Level and Pan first. These quick controls sit above the track’s state cards.
  2. Choose Direction, Playback, start/stop behavior and synchronization. Loop repeats the phrase; 1 Shot plays it once. Tempo Sync chooses memory tempo or original recording tempo.
  3. Check the input cards below: MIC, INST and Rhythm decide what is recorded onto this track. Check Rec Source separately if you want to include other tracks through Bounce.

Editing these file settings does not start audio or move a control on the pedal immediately. Use the effect previews to audition supported effects in the browser, and the save workflow to apply parameters to the RC-600.

04 / MEMORY TABS

What each memory tab does

Select a memory in the list before editing. Changes are kept as edits in the editor until you save them. Selecting another memory lets you work on several memories before using Save all.

Info
Change the memory name. The heading identifies the selected memory and the file version loaded by the editor.
Loop → Tracks
Select Track 1–6. Set Play Level, Pan, Reverse, one-shot playback, start/stop behavior, overdub mode, measures and synchronization. The Input switches choose which sources are recorded onto that track.
Loop → Record
Set memory-wide recording behavior, including recording options and bounce-track settings.
Loop → Play
Set shared playback behavior, including which tracks respond to All Start and All Stop.
Loop → Rhythm
Choose rhythm settings such as pattern, kit, level and tempo. This is the pedal's rhythm configuration for the selected memory.
Audio
Manage the recorded WAV phrases for the six tracks. See the next section for folder requirements.
Ctl Func → Mode 1 / Mode 2 / Mode 3
Choose what the pedal switches do in each control mode.
Ctl Func → Ext Ctrl
Configure external control switches and expression pedals.
Assigns
Configure the 16 assignments that link a control source to a parameter target. Enable the assignment, choose Source and Target, then set its range and behavior. For example, a MIDI CC source can control an effect parameter when the pedal is configured to receive that CC.
Input → Setup / EQ / Dynamics
Configure incoming signals, their equalization and dynamics processing.
Output → Setup
Configure output behavior for the selected memory.
Output → Routing → Track / Input/Rhythm / Phones Out
Choose where tracks, incoming audio and rhythm are sent, and what you hear in headphones.
Output → EQ / Master FX
Adjust output equalization and the final master processing.
Mixer → Input / Output
Balance input and output levels. Check here when a source is too quiet or a destination is not receiving the expected signal.
Input FX / Track FX
Edit effects before recording or on track playback. Both have Setup and Bank A–D pages.

A simple first edit

  1. Select a memory and open Loop → Tracks → Track 1.
  2. Adjust Play Level to change the track's playback volume.
  3. Check Loop Sync and Tempo Sync. Open their information buttons before changing them: loop alignment and tempo matching serve different purposes.
  4. Use Save memory, then follow the transfer steps in Save & backup.

INPUT, OUTPUT & MIXER

Shape the tone and follow the audio path

Input and output EQ: a console or a card grid

Open Input → EQ, select the channel, then use EQ for the fader board or Cards for individual numeric controls. Your view choice is remembered. The board orders parameters from low frequencies to high frequencies, followed by output level.

  1. Turn the EQ Switch on when you want it applied.
  2. Use Lo Cut or Hi Cut to remove an end of the spectrum. Gain at 0 dB leaves that band unchanged.
  3. For a mid band, set Freq to choose the area, Q to choose its width and Gain to boost or cut it. A higher Q narrows the band.
  4. Use Level to balance the result. Compare against the bypassed setting on the pedal after saving.

The EQ effect inside Input FX / Track FX has its own response graph and audio preview. See Visual effect editors; the channel EQ page and the effect slot are different places in the signal path.

Routing: decide where each source goes

Open Output → Routing and choose Track, Input/Rhythm or Phones Out. Check the source and destination together. If a loop is missing from an output, inspect its routing before raising every level.

Mixer: balance after routing

Open Mixer → Input for incoming sources or Mixer → Output for destination levels. On an input Level slider, the far left is Mute, the center is 0 and the far right is +100. There is no separate input mute switch.

For shared input/output settings, check the System Preference cards. Choose Memory for individual setups or System for a shared setup, then save the corresponding workspace.

CONTROLS & ASSIGNMENTS

Configure the switches you actually use

Ctl Func → Mode 1 / Mode 2 / Mode 3 lays out the nine switches in the same order as the pedal. On a wide screen, the three top switches appear above the six track switches. Click a function card and search by track, effects, rhythm or function name.

In Ext Ctrl, each jack groups its CTL Push, Hold and Click functions with the corresponding expression pedal’s function, Min and Max. In System → Ctl Func → Preference, choose whether each control follows Memory or System.

Assigns: connect a source to a target

  1. Open Assigns and choose one of the 16 assignments.
  2. Enable its switch and select the Source. For MIDI CC control, the pedal must receive that CC on the correct channel.
  3. Select the Target, then check its minimum, maximum and control behavior.
  4. Save the memory and test the source on the pedal. Ctl Func gives a switch its normal action; an assignment adds control of a chosen parameter.

05 / WAV AUDIO

Manage the recordings on each track

Open Memory → Audio. Each card represents one track, with its phrase status, duration and available audio actions. Use individual playback or Play all / Stop all to listen through the browser.

Audio playback needs the actual WAVE files. Settings alone do not contain recordings. Open the full ROLAND folder, including its WAVE folder, when requested by the Audio page.

Use a track's import action to choose replacement audio, export to keep a WAV copy, or remove to clear its phrase. Import and removal require writable folder access; follow any backup and format messages before proceeding.

Audio changes can write to files immediatelyAudio file operations use the connected folder and are separate from saving memory parameters. Keep a full backup before replacing or removing a recording; Discard memory is not an undo for WAV file changes.

06 / EFFECTS

Input FX and Track FX, step by step

Input FX

Process incoming audio. Use this area to shape what goes into your loops.

Track FX

Process the loop tracks during playback. Use this area to transform recorded phrases.

  1. Open Input FX or Track FX.
  2. In Setup, choose the selected bank and its behavior. SINGLE allows one effect slot at a time; MULTI allows several slots.
  3. Open Bank A, B, C or D. Click the effect tile or Library to browse presets for that slot. The Switch card cycles Off → Toggle → Moment; Insert chooses which inputs or tracks the slot processes.
  4. Click Edit to open the dedicated editor. Its Effect selector can change the effect type. THRU passes the signal through and has no effect parameters to edit.
  5. Click Library to browse available effect presets. Search by name or category, then click a preset to apply it to the selected slot. Factory presets are starting points; My effects holds your saved custom settings. Use Save to My effects to keep the current sound. Save the memory separately to put it in its RC0 files.
  6. Save the memory when you are happy with the settings.

Changing an effect here edits memory files. The editor does not send every effect parameter to the pedal in real time over MIDI. Save and reload the memory on the pedal to use the updated file settings.

LISTEN WHILE YOU EDIT

Preview an effect before saving it

Many dedicated effect windows include a Play bar. It generates an example phrase or loop in the browser and processes it with the settings shown below. You can change supported parameters while the preview plays and hear the comparison immediately. You do not need MIDI or the pedal connected for these synthesized previews.

  1. Open Input FX or Track FX, choose a bank and click a slot’s Edit.
  2. Click Play. Listen through the computer/browser audio output. Start with a comfortable listening volume.
  3. Set BPM for the preview, tap Tap at least twice in time, or click Memory to use the saved memory tempo when offered. Preview BPM does not replace the memory’s rhythm tempo.
  4. Change one parameter at a time. For a delay, compare Time, Feedback, then E.Level; leave the others steady while listening.
  5. When offered, use Effect ON/OFF to compare the effect, or Auto for the clean/effected demonstration cycle. Sequencer previews also offer Tap On / Tap Off to simulate switching.
  6. Click Stop when finished. Close the editor window, check the slot’s Switch and Insert, then save the memory.

Match the preview to the effect

Delay uses a guitar phrase; EQ uses a full-range band loop; Preamp uses synthesized guitar through an amp/cabinet/microphone chain; Freeze uses a held chord with melody. Sequencers offer a Sound choice and metronome. Read the information icon beside the preview’s name to learn what it demonstrates.

Separate the three kinds of audio

Effect preview: a generated demonstration played by the browser. Memory → Audio: your recorded WAVE phrases played by the browser. Play Drum: MIDI notes sent to the pedal, heard from its outputs.

What you are hearing: these previews are browser approximations, useful for understanding the adjustment and comparing settings. They do not reproduce the RC-600’s exact algorithms, process the pedal’s live input or audition your saved track WAVs. Confirm the final sound on the pedal after saving and reloading. Available preview controls vary by effect.

A first listening exercise: delay

Load Delay Classic Echo from Library and click Edit → Play. Change Time to hear the spacing between repeats; increase Feedback to hear more repeats; change E.Level to balance the echo against D.Level (the direct sound). Try a note-based Time and change preview BPM to hear the synchronized spacing. Stop and save only when you want to keep the settings.

DEDICATED EFFECT EDITORS

Use the picture that explains the sound

EQ: see the frequency response

The EQ effect editor shows its response curve above the faders. Left is bass, right is treble; a rise shows a boost and a dip shows a cut. Freq moves a mid band’s position, Q changes its width, and Gain changes its height. Adjust the faders and watch the curve update while the Band loop preview plays.

Preamp: amp, cabinet and microphone

Use the picture selectors for Amp Type and Speaker Type. Choose a microphone from its pictured list, click the speaker to set its position and select Off Mic / On Mic distance. The faders below group Gain, T-Comp, Bass, Middle, Treble, Presence and E.Level.

DIST: choose the character, then balance it

Pick Vocal, Boost, Overdrive, Distortion, Metal or Fuzz from the type tiles. Dist controls saturation; Tone runs from Dark to Bright. In Mix, D.Level is the direct signal and E.Level is the processed signal. The Guitar riff preview lets you compare the character as you edit.

Freeze: read the envelope

The graph shows Attack → Decay → Sustain → Release. Attack controls fade-in, Decay the time to settle, Sustain the held level, and Release fade-out after switching off. The shaded interval represents the switch being held on. The text beneath translates the settings into times and held level.

Musical controls instead of raw numbers

Delay Time and supported rates offer musical note values as well as time-based settings. Filter cut controls show the band being removed. Balance controls show Direct at one end and the effect at the other. Pitch editors can show note keys, intervals and waveform pictures. Their information buttons explain which parameter each visual represents.

STEP-BY-STEP MODULATION

Draw a pattern and hear it move

Effects with a step editor show numbered bars. Instead of setting one constant value, you create a series of values that repeats over time. The available target depends on the effect: level, cutoff, note, pitch or another supported parameter.

  1. Load a sequenced effect or a Step Slicer preset and click Edit. If the editor has a Sequence card, turn it on; when Off, the pedal ignores its steps and preview Play stays locked.
  2. Choose the Target when offered. Check the “Steps change…” caption so you know what the bars control.
  3. Set Step Max for the active number of steps and Sequence Rate or Rate for their timing. Rate controls step speed; preview BPM supplies the tempo for note-based timing.
  4. Drag the bars to draw the pattern. Step Slicer offers Level, Length and Both: Level changes step volume and Length changes how long the step sounds.
  5. Click Play, select a Sound and enable Metronome if useful. Tap On / Tap Off lets you hear switching behavior.
  6. Try Pattern and Random for a starting pattern. The optional Rate, BPM and Steps buttons also randomize those values; inspect them before generating a new pattern.
  7. Where supported, Step Sync decides how the sequence aligns with loop playback, and Retrigger decides whether switching on restarts step 1. Open their help icons, then test the saved result on the pedal.
Try a simple pulse: start with Step Slicer, use 8 active steps, alternate high and low Level bars, and press Play. Switch to Length to shorten the hits. Increase Rate to hear the same pattern move faster. Save the memory or a My effects preset if you want to keep your pattern; preview playback itself is not a recording.

07 / SYSTEM TABS

Configure the pedal's shared settings

Open System after loading your settings files. These pages edit system settings separately from memory edits.

Input → Setup / EQ / Dynamics
Shared input configuration and processing. Preference controls choose whether the pedal uses MEMORY or SYSTEM settings where supported.
Output → Setup / Routing / EQ / Master FX
Shared output configuration and processing. Routing includes Track, Input/Rhythm and Phones Out pages.
Mixer → Input / Output
Shared level settings. Check Preference if you want a consistent mix across memories.
Ctl Func → Mode 1 / Mode 2 / Mode 3 / Ext Ctrl / Preference
Shared switch and expression-pedal functions. Preference chooses which controls use memory-specific settings or shared system settings.
USB
USB audio and connection settings. Changing Storage in a file is not a command to enable USB Storage on the pedal; use its physical menu.
MIDI
Global MIDI settings, including channels and receive/transmit behavior. Match these settings to the MIDI connection bar when using live control.
Setup
General pedal setup, display colors and knob functions.
Memory or System?Editing a memory's input settings may have no effect on the pedal if its Preference uses SYSTEM. Conversely, shared settings do not override a section configured to use MEMORY. Check Preference, then use Save system for system changes.

08 / SAVE & BACKUP

Make your changes reach the pedal

Save memory
Save parameter changes for the selected memory.
Save all
Save parameter changes for all edited memories. Save System separately.
Save system
Save edits made in the System workspace.
Discard memory / Discard all
Remove unsaved memory parameter edits for the selected memory or all memories. These actions do not restore audio files already changed on disk.
Copy / Mass Apply
Copy chosen groups of memory settings, then apply them to selected destination memories. Review the groups and destinations carefully. Save the affected memories afterward.
Export ZIP
Download the currently loaded files. After importing without write access, save your parameter edits before exporting the result.

If you used Open folder

  1. Confirm your backup, then click Save memory, Save all or Save system, as appropriate.
  2. Wait for the success message. Changes are written to the selected folder. If that folder is on your computer, transfer its updated files to the pedal.
  3. If working on the pedal drive, use Eject USB when shown and follow the disconnection instructions. If asked, eject the drive in your operating system.
  4. After leaving Storage, select another memory on the pedal and return to the edited one so it reloads the saved settings.

If you used Import folder or Import ZIP

  1. Save the edited memories and System settings in the editor.
  2. Click Export ZIP and extract the downloaded archive on your computer.
  3. With a backup already safe and the pedal in USB Storage, copy the exported files into the corresponding locations on the pedal. Preserve the folder structure and your original WAVE recordings.
  4. Eject safely, leave Storage and reload the memory on the pedal.
Keep both parts of the backupDATA holds settings; WAVE holds recorded audio. A settings-only import or demo cannot recreate missing recordings. Save needs the editor's online service; wait for a confirmed success message before disconnecting.

09 / LIVE MIDI

Control the pedal while playing

  1. Leave USB Storage mode before using the pedal for live MIDI or audio.
  2. Use the MIDI connection controls at the top. Allow MIDI when the browser asks, then select the RC-600 MIDI output.
  3. Set RX CH to match the pedal's receive channel. Check System → MIDI and the pedal's own settings.
  4. Use supported memory selection and configured MIDI actions. Assigns determine how the pedal responds to incoming control changes.

MIDI carries control messages, not recorded WAV files. Connecting MIDI does not download all pedal settings into the editor, and editing file parameters does not automatically send them live.

On iPhone/iPad browsers without Web MIDI, the editor offers a link to Web MIDI Browser. You can still read this guide in any browser. Direct folder editing and live control depend on the capabilities of the browser you use.

10 / PLAY DRUM

Play drum pads and build loops

Open Play Drum and connect MIDI. This workspace can run without loading a memory folder. Its pads send notes to the RC-600; hear the sound through the pedal's outputs.

  1. Choose a kit from the kit gallery, or load a drum preset.
  2. Set Pads, BPM, Meter and Vel (how strongly a note is played).
  3. Click or tap a pad to trigger its assigned note. Open Show pad settings to change its note, velocity and hits per bar.
  4. Enable a pad's loop, then use Play All and Stop All for the pattern.
  5. Use Full screen for a larger performance view. Save a kit or preset from its gallery when you want to reuse your setup.

Play Drum presets are browser/editor resources. They are separate from the pedal rhythm settings in Memory → Loop → Rhythm. Check the rhythm MIDI channel and kit configuration if notes produce unexpected sounds.

11 / SETLISTS

Prepare songs for a performance

Open Setlists after the editor is unlocked with your license key.

  1. Click New setlist, give it a name, then use Add song.
  2. Expand a song to edit its information. Open Music guide to prepare a scrolling chart or score, and Triggers to configure supported MIDI actions.
  3. Use the music editor to add lyrics/chords or a supported score file. Set the visible tracks and playback options for a score.
  4. Click a setlist card or its View button to enter live view. Use Edit when you want to change the songs.
  5. With MIDI connected, use the configured song actions to select memories or send control messages.
  6. Use Export to keep a portable copy and Import to load one. Keep backup copies of source score files as well.

Score playback includes options for metronome, audio and playback speed. Keep playing lets score audio continue after closing the viewer or leaving Setlists; a floating player brings you back. Stop, the end of the score or turning the option off ends that playback session.

Setlists are stored in this browser. They do not become RC-600 memory files when you click Save memory. Clearing browser data or changing browsers can affect access to locally stored material, so export your setlists regularly.

12 / TUNER

Tune using a browser audio input

  1. Open Tuner and leave USB Storage if the pedal is still in that mode.
  2. Select the audio input you want to analyze and start listening. Allow microphone/audio-input access when the browser asks.
  3. Play one sustained note. Read the note name and pitch indicator, and tune until it centers.
  4. Adjust the A4 reference if your setup uses a pitch other than 440 Hz.
  5. Stop listening when finished.

The tuner analyzes audio reaching the browser. A MIDI connection alone does not carry your instrument sound; use an appropriate audio input or interface.

13 / TROUBLESHOOTING

When something does not work

Memory or System is empty

Open a ROLAND folder or import files containing DATA settings. Connecting MIDI alone does not load them. Try Demo fixtures to check the editor first.

Save is disabled

Make a change, confirm your backup and check that the editor service is online. System changes use Save system. Folder imports require Export ZIP afterward.

The pedal still has the old settings

Check which folder you edited. A computer backup is not the pedal drive. Transfer your updated files, leave Storage and switch to another memory and back. Check MEMORY/SYSTEM Preference for shared settings.

There is no MIDI output or drum sound

Leave Storage, allow MIDI access and check the selected port and channel. Listen through the pedal, and check its rhythm MIDI settings and output levels. Use a browser that exposes Web MIDI.

Audio tracks will not play or import

Open the full ROLAND folder with WAVE files. Check that a track has recorded audio. Imports and removal require writable folder access; use the page's error message to resolve format or access problems.

The effect preview is silent or Play is locked

Click Play to start browser audio, check the browser tab is not muted and check the computer’s output device. If the effect has Sequence, turn it on. Some previews also need Effect ON or Tap On; inspect direct/effect levels and the preview information icon. MIDI output selection does not select the browser’s audio output.

The graph moves but the pedal does not change

The graph reflects file edits in the browser. Save and transfer the memory, leave USB Storage and reload that memory on the pedal. For a preview, the audio comes from the browser. Check Switch, Insert, routing and Memory/System Preference for the final pedal result.

The tuner does not detect notes

Check audio-input permission, the selected device and its input level. Play a single clean note. MIDI alone is not an audio input.

The editor asks for a license key

Enter your license key on the activation page. The editor, including Setlists, opens after the key is accepted.

14 / KEEP THIS GUIDE

Print it or save a PDF

Click Print / Save PDF at the top. In your browser's print window, choose Save as PDF or a printer. The printed guide uses a white background in either theme. On a phone, the print or share menu may offer a PDF option.
