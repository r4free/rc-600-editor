# RC-600 Editor — Feature registry / Registro de funcionalidades

**Version:** pre-release · **Updated:** 2026-10-06

Shared ritual: https://github.com/r4free/boss-editor-guidelines (`shared/feature-registry.mdc`).

## EN

### Shipped

- **Memory list:** selecting a memory scrolls the list so that memory sits at the top.
- **Navigation breadcrumb:** the path above the workspace content follows the currently visible tabs, including nested tracks, routing and EQ channels. Earlier levels return focus to that level's tabs without resetting edits or changing the pedal.
- **3D Model panel:** next to Chain, open a photo-textured RC-600 model with rotation, keyboard controls, zoom, panel and rear views. This first integration is visual only.
- **System → Setup:** Contrast and Memory Ext Min / Max are scrub cards. Display Mode, Loop Indicator, Orb Indicator and Auto Off are click cards. Rec, Play, Dub, Stop and Blank step through the indicator colors. Knob 1–4 open a searchable list grouped by track, effects, rhythm, levels and the rest. Off is dimmed.
- **System → MIDI:** Rx CTL, Rx Rhythm, Rx Voice and Tx channels are scrub cards (wheel, sideways drag or arrows). Tx can also sit on Rx CTL. Sync Clock, Start and the two Thru settings step through their choices on click. Clock Out and PC Out are on/off cards. The page has no extra MIDI heading, because that name is already the selected tab. PC Out stays explained on its card.
- **System → USB:** Input Level and Output Level use the segmented level slider. Storage, Audio Mode and Routing are cards: Storage stays on Connect while the editor is using the folder, Audio Mode steps Generic / Vendor, and Routing steps Line Out / Sub Mix / Loop In. The page has no extra USB heading, because that name is already the selected tab.
- **Ctl Func → Preference:** Mode 1–3, CTL 1–4 and EXP 1–2 are Memory / System cards, the same control used in Input and Output setup. All Clear is an on/off card. The page has no extra Preference heading, because that name is already the selected tab.
- **Ctl Func → Ext Ctrl:** each jack is a group. CTL 1, 2 / EXP 1 holds CTL 1 and CTL 2 (Push, Hold and Click cards) plus EXP 1 (function card, then Min and Max). CTL 3, 4 / EXP 2 is the same for the other jack. Click a function card to search. Min and Max are changed with the wheel, a sideways drag or the arrows. Off is dimmed. The same layout is on Memory and on System.
- **Ctl Func → Mode:** the nine onboard switches follow the RC-600. On a wide screen, Track Select, Undo/Redo and All Start/Stop are three cards across the top, and the six switches below are one row, left to right (REC/PLAY, STOP, REC/PLAY, STOP, REC/PLAY, STOP). On a phone they stack in that same order, starting at the top-left switch. A card shows the pedal number, the name printed on the unit, and the function assigned now. Off is dimmed. Click a card to search the function list, grouped by track, current track, effects, rhythm and the rest. The same layout is on Memory and on System.

- **System requirements:** the activation screen has a **System requirements** button that opens a window you can copy. It says the editor runs in any modern browser, including phones and tablets, and that live MIDI does not work in Safari or Chrome on iPhone and iPad. Opening the site in Web MIDI Browser (App Store) enables live MIDI there; on a computer, Chrome or Edge is enough.
- **Pedal photo on the activation screen:** a picture of the RC-600 sits above “Your RC-600, easier to organize.” so the pedal is clear before you enter a license key.
- **Paid activation:** on the hosted site, a welcoming first screen introduces the editor's memory, backup/MIDI, and performance tools; returning users can enter a license key, while new users can open Stripe Checkout or explore the user guide. The key is sent by email after payment and never expires. The editor pages and scripts stay on the server until that key is accepted. Local development still opens the editor without a key.
- **User guide:** the Guide link opens an expanded English visual walkthrough with current editor screenshots, card/slider/fader gestures, EQ and routing, pedal controls, dedicated effect editors, step sequences and browser audio previews. Includes listening exercises, file/MIDI workflows, troubleshooting, light/dark themes, keyboard-accessible image enlargement and printing to PDF.
- Memory / looper oriented web editor for the Boss RC-600.
- Horizontal editor tabs and English-only UI (see Cursor rules).
- Links to sibling VG / GM / GT / TONEX editors.
- On iPhone/iPad browsers without Web MIDI, a dismissible warning recommends opening the site in **Web MIDI Browser** (App Store), and MIDI Connect is enabled when that API is present.
- **Setlists:** live charts, score guides, and setlist editing are part of the editor. On the hosted site they open with the same license key as the rest of the app. Setlists already saved in this browser stay in this browser.
- **Keep playing** on alphaTab scores (opt-in): audio keeps going after you close the live viewer or leave Setlists. A floating mini-player shows the song on any screen and restores the viewer; the toggle is remembered in this browser. Stop, turning Keep playing off, or the end of the piece clears the session (playback itself does not resume after a full page reload).
- **Rhythm Converter (Guitar Pro → RC-600 rhythm):** opens full screen from the **Rhythm Converter** button next to **Tuner**; **Close** goes back to the editor and keeps the open file and edits until the page is reloaded; it asks first when the rhythm parts are not saved to a slot or the Rhythm Library, or the offline slot list was not downloaded. Windows close only with their Close button (not Esc or a click outside). Whether the converter is open is remembered across reloads. Drop or choose a Guitar Pro (.gp3, .gp4, .gp5, .gpx, .gp), MusicXML or MIDI (.mid) file. The drum track is found automatically (for MIDI, channel 10). Under **Tracks** you can click several tracks to merge them into one rhythm (for example drums plus percussion, or kick and snare written on separate tracks); only drum tracks are listed; melody, bass and other instruments are hidden (with a count), and a file without drums says so. MIDI files list each track and channel separately and use Marker events as section names. Repeats are written out. The converter then suggests the rhythm parts: **Intro**, **Variation A–D**, **Fill A–D** and **Ending**. It uses the song's section markers when they exist (Intro, Verse, Chorus, Bridge, Outro…, also in Portuguese such as Refrão, Ponte and Virada). Without markers, it finds the repeated grooves, the bars that break them (fills), and what comes before and after. Each part shows how sure the suggestion is. The **Magic Wand** button next to the file name fills every part at once (Intro, Variation A–D, Fill A–D, Ending): it groups the bars that play the same groove, takes the most played grooves as Variations, the bars that break each groove (toms, snare, right before a new section) as their Fills, and the bars before the first and after the last groove as Intro and Ending. It builds up to 8 arrangements (more or fewer Variations, song order or most played first, shorter or longer loops, another fill, shorter Intro or Ending); 1 is the best match and the numbered buttons switch between them, with Undo to go back. A bar strip, colored by part, lets you click or drag bars to change any part. **Play Song** plays the whole drum track from any bar, following it on the bar strip, and **Play** loops one part as it will be saved. **Sound** picks the drums for both: Standard, Room, Jazz or Brush (sampled General MIDI kits), Basic or Electronic Synth, or **RC-600 Kit (MIDI)**, which plays the pedal itself and switches it to the chosen Kit when the memory has a Rhythm Kit assign. Options: Quantize (Off, 1/16, 1/32, triplets), Velocity (50–150%), Fill Length (1 bar or half bar), Humanize and Kit Notes Only. Guitar Pro extras such as rim shots, half-open hi-hats and choked cymbals become the nearest kit sound. A warning appears when a part uses a different time signature. Under **RC-600 Rhythm** you set the rhythm **Name** (up to 12 characters), **Kit** and **Slot** (a new user slot or one to replace). **Save to RC-600** writes the rhythm straight into the pedal's user rhythm file (`ROLAND/DATA/RHYTHM.RC0`, the same file BOSS RC Rhythm Converter writes) on the open RC-600 drive, keeping the other user rhythms; it then appears under Rhythm → Genre: User. Without the pedal the button reads **Save to Offline Slot** and saves into the offline list under **RC-600 Slots**, where **Download RHYTHM.RC0** gives the file to copy by hand. **Export ZIP** still downloads one Standard MIDI File per part (01_Intro … 10_Ending) and a README, for anyone who prefers BOSS RC Rhythm Converter. The bar strip is grouped by song section: each block is one bar, with a color band for its part and a small picture of what plays (cymbals, hi-hats, toms, snare, kick); a color legend shows the parts. **Layout** shows one row per section or a fixed 4, 8 or 16 bars per row. Click or drag across bars to **select** them (for example bars 4 to 8; Shift+click or **First Bar**/**Last Bar** also work), then **Play** the selection, **Save to Library…** with a category and tags, or **Use As** to put it straight into a part of this rhythm. **Undo** and **Redo** (Ctrl+Z, Ctrl+Shift+Z) step back and forward through bar ranges and part edits. **Reset Parts** above the parts empties every part to start the rhythm over (Undo brings them back). The **Edit** button on each part card opens that part in its own editor window, with two views. **Instruments** is a step grid with one row per drum sound (cymbals on top, kick at the bottom): click or drag to add and remove hits, right-click to switch Ghost, Normal or Accent, choose the Grid (1/8 to 1/32, triplets) and add more kit sounds. **Blocks** shows the part's bars as cards to move, duplicate, copy, paste, clear, delete or add, and opens any bar in Instruments. Edits play live while the part loops, have **Undo** and **Revert**, and are what gets saved; a part can also start empty, without a file. The **Part Library** keeps reusable parts with a name, a **category** (Intro, Variation, Fill, Ending) and **tags**: ready-made style tags (Rock, Pop, Funk, Samba, Bossa Nova, Forró, Baião, Xote, Sertanejo, Axé and more), feel tags (Half Time, Shuffle, Ballad…) and your own. Save a bar selection or any part of the rhythm, filter by category, tags or name, play a part, edit its name, category and tags, and **Use As** to place it in this rhythm, then edit it under **Edit** (also without opening a file). The library opens in its own window from **Part Library** above the parts, or from the **Library** button on each part (Intro, Variation A–D, Fill A–D, Ending), which lists only parts of that category; **Use for …** places the chosen part, so a whole rhythm can be built from library parts alone. Parts you save stay in this browser; **Export** and **Import** move them to another computer. Factory parts come with the editor. **Rhythm Library** holds ready-made rhythms: **Save Rhythm…** above the parts, **Save to Rhythm Library…** at the bottom (or **Save Current Rhythm…** in the library) stores every part plus Kit with a name and tags, and the library button on an RC-600 slot saves that slot the same way; with **Add Parts to Part Library** ON (the default), each part is also saved on its own in the part library, named after the rhythm and tagged with the rhythm name; **Load** puts the whole rhythm back in the builder, where any part can still be swapped or edited. Tick several rhythms and use **Save to RC-600** to write them all at once. Every user rhythm (up to 50) lives in one file, ROLAND/DATA/RHYTHM.RC0: a rhythm whose name is already on the pedal replaces that slot, the others take the next free slots, and rhythms already on the pedal are kept. **Download RHYTHM.RC0** builds the same file to copy by hand; without the RC-600 drive open it holds only the chosen rhythms and asks before you continue, since copying it replaces every user rhythm on the pedal. The **Rhythm Player** above the parts plays the whole rhythm the way the pedal runs it (Intro, each variation followed by its fill, Ending) with **Play Rhythm** / **Stop**: click parts to leave them out or put them back, set **Variation Repeats** (1–8), **Tempo** (preview only) and **Loop**. The part being played is highlighted in the list and the editor grid follows it, and edits are heard on the next pass. **Play Part** in the editor still loops just the part being edited. **Import from RC-600** (in the Rhythm Library) reads the user rhythms already on the pedal, from the open drive or a picked RHYTHM.RC0 file: tick the ones you want and they go to your rhythm library (tagged From RC-600), and with **Add Parts to Part Library** ON their Intro, Variations, Fills and Ending also go to your part library, named after the rhythm. Parts the pedal only reuses are skipped, and the pedal is not changed. Bars without drum hits are hidden from the bar strip by default so long files are easier to scan; turn on **Show Empty Bars** to see them (the choice is remembered). When you select bars, the converter classifies them automatically: **Looks like** shows the likely category (Intro, Variation, Fill or Ending, from section markers, the position in the song and the groove, such as toms and snare rolls for fills) and style and feel tags (Pop Rock, Shuffle, Swing, Reggae, Latin, Disco, Waltz, Half Time, Slow / Medium / Fast…), with a one-click **Use for** the suggested part; **Save to Library** starts with that category and those tags. **Other Part** opens a menu of all ten parts with their colors, what each one holds now and the suggested part highlighted. Repeated bars are hidden by default too: only the first of identical bars (same drum notes on the same steps) is shown, with a ×N badge for how often it occurs, so each different groove and fill appears once; turn on **Show Repeated Bars** to see every bar. **Suggested Kit:** after importing a song, the editor picks the RC-600 kit that fits its groove (Rock for a straight backbeat, Light for ballads, Jazz or Brush for swing, Cajon for Latin percussion, Dance or Techno for four-on-the-floor, Metal for double bass drum, and so on), marks it in the Kit list and explains why; choosing another kit keeps your choice. The Kit is saved as the rhythm's default kit on the pedal. **RC-600 Slots:** a list of the pedal's 50 user rhythm slots, with or without the pedal connected. With the RC-600 drive open, every change is written to the pedal; without it, open a RHYTHM.RC0 (a backup) or start an empty list, and the offline list stays in the browser until you download it and copy it to ROLAND/DATA. Each slot can be played, loaded into the builder to edit (Save to Slot then replaces it), picked as the target of the next save, renamed, moved up or down, and deleted. A bar at the top shows both places side by side, the offline list in this browser and the RC-600, and which one is shown. **Connect RC-600** opens the USB Storage steps without leaving the converter. With the pedal connected, **Add to RC-600** sends the offline list to the pedal (keeping its rhythms; same name replaces), **Replace RC-600** makes the pedal match the offline list exactly, and **Copy to Offline** keeps a copy of the pedal's rhythms in the browser to work without it. **Backup done — unlock save** can be confirmed right there. **RC-600 Kit Preview** (the default Sound) plays a browser model of each of the 16 RC-600 kits (Studio, Live, Light, Heavy, Rock, Metal, Jazz, Brush, Cajon, Drum & Bass, R&B, Dance, Techno, Dance Beats, Hip Hop, 808+909), with a Kit picker next to Sound, so you hear roughly how the rhythm will sound on the pedal without connecting it.
- **Comfortable dark interface:** clearer headings and parameter groups, roomier controls, softer panels, consistent keyboard focus and selection states, and a prominent unsaved-changes indicator make the existing editor easier to scan without changing its navigation or workflows.
- **Quick volume controls:** track, mixer, and effect volume parameters move to the top of their group and use a compact segmented slider. Active bars graduate through green up to 100, then orange, red, and dark red above 100. A small reset button to the left of the value returns Play Level (and other volume controls) to the default, which is 100 for Play Level. In Mixer → Input, each mic and instrument Level reads **Mute** at the far left, **0** in the middle (the default level) and **+100** at the far right. There is no separate Mute switch: the far-left position mutes the input.
- **Centered pan controls:** track and effect pan parameters use a compact segmented slider whose tall ends and low center make the stereo position immediately visible. A small reset button to the left of the value returns pan to center. When Volume and Pan share a group, they form a two-column quick-control header.
- **Track playback direction card:** in Loop → Tracks, Reverse is shown as a compact Direction card next to Play Level and Pan. A green arrow spinning clockwise means the track plays **Forward**; a red arrow spinning counter-clockwise means it plays in **Reverse**. Clicking the card switches direction. 1 Shot works the same way in a Playback card: a green repeat icon for **Loop**, or an amber "repeat once" icon for **1 Shot**. Bounce In appears as a Rec Source card: a green microphone for **Input** (inputs only) or a violet merge icon for **Bounce** (inputs plus other tracks' playback). Loop Sync appears as a card showing **Synced** (green link) or, highlighted in amber, **Free** (broken link). Loop Sync Mode has three values, so each click steps Immediate → Measure → Loop Length: a fuchsia lightning bolt for **Immediate** (starts when you press the switch), a lime ruler for **Measure** (waits for the next measure) and a green repeat icon for **Loop Length** (follows the LOOP LENGTH setting). Tempo Sync shows **Memory** (green metronome) or, highlighted in pink, **Original** (recording tempo). FX shows **Wet** (green waveform, Input FX / Track FX applied) or, highlighted in orange, **Dry** (bypassed). Start Mode shows **Immediate** (green play icon) or, highlighted in yellow, **Fade** (rising ramp). Play Mode shows **Multi** (green stacked play boxes) or, highlighted in indigo, **Single** (one play box). Tempo Sync Mode appears as a Tempo Sync Mode card: **XFade** (green swap arrows, keeps pitch) or, highlighted in rose, **Pitch** (music note, pitch follows tempo). Tempo Sync Speed has three values, so each click steps Half → Normal → Double: a blue slow gauge for **Half**, green for **Normal**, an orange fast gauge for **Double**. Stop Mode steps the same way through **Immediate** (green stop icon), **Fade** (yellow falling ramp) and **Loop End** (purple arrow to the end). Dub Mode steps through **Overdub** (green layers icon, new material on top), **Replace 1** (red replace icon) and **Replace 2** (orange replace icon); both Replace values overwrite the existing take while you record. Measure cycles Auto → Free → a measure count that you scrub with the wheel, a sideways drag or arrows; clicking the number returns to Auto. Loop → Record uses the same cards for Rec Play Action, Quantize, Auto Rec, Bounce and Bounce Track 1–6. These state cards sit in an evenly spaced grid right below the Play Level and Pan quick controls, which stay first. The track's Input section uses the same cards for MIC 1/2, INST 1/2 L/R and Rhythm: a green microphone, guitar or metronome when the input is recorded onto the track, dimmed grey when it is left out. In Loop → Play, Single Track Change and Speed Change toggle **Immediate** (lightning bolt) / **Loop End** (violet), Sync Adjust toggles **Measure** / **Beat** (lime), and Fade Time In, Fade Time Out and Loop Length are scrub cards: change the value with the mouse wheel, a sideways drag on touch screens or the two arrows (Loop Length 0 shows **Auto**). In Loop → Rhythm, Genre, Pattern and Kit stay as lists; Variation cycles **A** → **B** → **C** → **D**, Start Trig cycles Loop Start → Rec End → Before Loop, Stop Trig cycles Off → Loop Stop → Rec End, Intro Rec / Intro Play / Ending / Fill are on/off cards, Variation Change toggles Measure / Loop End, and Beat is a scrub card (2/4 … 15/8).
- **Input → Setup cards:** Phantom (MIC 1/2) shows **Off** or amber **+48V**; Gain (INST 1/2) toggles **INST** (guitar) and **LINE** (violet); Stereo Link (MIC, INST 1, INST 2) toggles **Off** and **Linked**. In System → Input → Setup, Preference (MIC, INST 1, INST 2) toggles **Memory** and **System**. Clicking the card switches the value. Input → EQ has two views, chosen with the **EQ / Cards** toggle (remembered). **EQ** is a console-style board: an ON/OFF Switch on top and one vertical fader per parameter grouped by band (Lo Cut, Low, Lo Mid, Hi Mid, High, Hi Cut, Output); gain faders grow up or down from 0 dB, frequency/Q faders fill from the bottom. Drag, mouse wheel or arrow keys change a fader, double-click resets it, and the board dims while the EQ is bypassed. **Cards** shows Switch as an on/off card and every band (Lo Cut, Lo Gain, Lo Mid Freq / Q / Gain, Hi Mid Freq / Q / Gain, High Gain, Hi Cut, Level) as a scrub card ordered from low to high — mouse wheel, sideways drag or arrows; cards differing from the default are highlighted. In Input → Dynamics, Comp and NS for each jack (MIC 1 Comp, MIC 1 NS, …, INST 2 NS) use the same segmented meter as Play Level — big value, bar that warms from green to orange as the effect gets heavier, Compressor / Noise Suppressor caption, laid out two per row (MIC 1 Comp | MIC 1 NS, MIC 2 Comp | MIC 2 NS, INST 1 NS | INST 2 NS — INST jacks have no compressor) with a microphone or guitar icon on the label and a squeeze (Comp) or gate (NS) icon by the value; Comp 0 reads **OFF**, and MIC 1/2 merge into MIC when stereo-linked. Output → Setup uses the same cards: Output Knob cycles **All** → **Master** (speaker) → **Phones** (headphones) → **Off**; Stereo Link (MAIN, SUB 1, SUB 2) toggles **Off** / **Linked**; and in System, Preference (MAIN, SUB 1, SUB 2, PHONES, Rhythm, Master FX) toggles **Memory** / **System**. Output → Routing → Track shows one column per output with Track 1–6 on/off cards (green play icon when the track is sent there). Output → Routing → Input/Rhythm starts with Rhythm Out (**Output** speaker / violet **Loop**), Input Thru (**Thru** microphone / amber **Muted**) and Phones Rhythm (**On** / greyed **Off** headphones, hidden when Phones Out is Individual), then one row per output with MIC, INST and Rhythm cards (green microphone, guitar or metronome when sent there, muted speaker when not). Output → Routing → Phones Out is one card that steps through the jacks — **MAIN** (green speaker), **SUB 1** (violet), **SUB 2** (blue) — and **Individual** (pink headphones), which gives PHONES its own routing. Output → EQ (MAIN, SUB 1, SUB 2 channels) has the same **EQ / Cards** toggle, fader board and cards as Input → EQ; its view choice is remembered separately. Output → Master FX is one row of three columns: an Insert card first, then Comp and Reverb as segmented meters with the same green-to-orange bar as Input → Dynamics. Each click on the Insert card steps to the next output jack — **MAIN** (green speaker), **SUB 1** (violet), **SUB 2** (blue), then **Off** — showing L/R separately when the output is not stereo-linked. When Insert is Off, Comp and Reverb are hidden because the effects are bypassed.
- **Input FX → Setup cards:** Selected Bank cycles **A** → **B** → **C** → **D** on click. Each bank (A–D) has its own color-coded group of three cards, labeled with the bank on top and the setting below: Switch (**On** / greyed-out **Off**), Mode (**Multi** stacked play boxes / violet **Single** box) and FX Target, which cycles **A** → **D** to pick the FX the expression pedal controls. Switching a bank to Single still turns off the other FX in that bank so only one stays on.
- **Input FX → Bank A–D cards:** the Bank A–D tabs use the same bank colors as Setup (A cyan, B indigo, C amber, D pink). Inside a bank, each FX has its own color on its title and cards (FX A green, FX B orange, FX C purple, FX D red). Each FX (A–D) of a bank is a row of three cards. **Switch** merges on/off and Switch Mode into one card; each click steps **Off** (greyed power icon) → **Toggle** (green, each press flips the effect) → **Moment** (amber, the effect sounds only while the switch is held) → back to Off. **Insert** steps through the inputs the effect is applied to — **ALL**, MIC and INST jacks (shown as MIC / INST when stereo-linked) — and wraps back to ALL. **Effect** shows the loaded effect; clicking it opens the effect library, and **Edit** opens its parameters. The **Effect library** is a large window: a category list on the left with counts, a search box, an **All / Factory / My effects** filter, and the presets as color-coded tiles grouped into My effects and Factory. Clicking a preset loads it and keeps the library open, with the loaded tile highlighted, so you can try several in a row. An **Edit** button next to Close jumps to the parameters of the current effect, and the Edit window has a matching **Library** button next to its Close. The top shows which bank/FX you are loading into and the current effect, and the bottom saves the current effect into My effects. The Edit window also has an **Effect** button at the top that opens a **Choose effect** window to switch the slot to any RC-600 effect directly, including effects with no preset in the library.
- **Capture effects from the pedal:** the Input FX **Effect library** has a **Capture from pedal** button. It reads every loaded memory (the active copy of each), goes through all four banks and four FX, and saves each configured effect (with all its settings and step sequence) to **My effects**, just like Save to My effects. Each one is named after the memory number, memory name and FX slot (e.g. "007 Funk Jam AB"). THRU slots are skipped, and an effect whose type and settings are already in My effects is not saved twice, so capturing again only adds what is new.
- **Input FX step sequencer:** effects that run on steps (Step Slicer, Tremolo, Phaser, Flanger, filters, pitch and pan effects with a sequence) show a step sequencer at the top of their **Edit** window. Sixteen bars set each step's value: drag up or down to set one, or drag across to paint several at once (arrow keys also work). The square under each bar sets that step to zero and clicking it again brings the previous value back. On Step Slicer the squares follow the view: Level, Length, or two squares per step in Both. **Random** generates a new pattern in the chosen **Pattern** style (Euclidean, Gate, Stutter, Accent, Chaos or Any). Steps past **Step Max** are dimmed. A help icon opens **About FX sequences**, the Parameter Guide reference for the sequence parameters. **Play** runs a reference sound through the sequence — a **Beat**, a **Tone** or a **Synth** arpeggio — at a BPM you choose (it starts at the memory tempo), with an optional **Metronome**, and the current step lights up. While it plays, **Tap** (or the T key) changes the step that is playing, so you can tap a rhythm in. A switch next to it picks what Tap does: **Toggle** (turns the step on if it is at 0, otherwise sets it to 0), **On** (only turns steps on, back to their previous value) or **Off** (only sets steps to 0). The preview only illustrates the sequence in the browser; it is not the real RC-600 effect. Every change is written to the memory like any other parameter. Sequence settings (Rate, Step Max, and for sequence effects Sequence, Step Sync, Retrigger and Mode) sit right below the bars. Step Slicer has a **Level / Length / Both** switch: Level bars set each step's volume, Length bars set how long each step sounds before it is cut (low = short, choppy slices; high = the sound fills the whole step), and Both shows the two bars side by side in each step — Level in the FX color, Length in cyan; its Depth, Comp Threshold and Comp Gain sit below the sequencer.
- **Visual Preamp editor:** the Input FX Preamp Edit window starts with Amp Type, Speaker Type and the speaker/microphone simulator side by side (stacked on mobile). Swipe an Amp/Speaker image left/right or tap anywhere on its full-height side strips to move between options; the arrows stay discreet and there is no extra slider track. In the simulator, the cabinet scene stays on the left and a vertical list on the right shows every Mic Type; clicking a microphone applies it immediately. Mic Distance uses the standard two-choice control. Its near/far drawing is illustrative and keeps the mic visible, while the exact stored setting is still sent to the pedal. Mic Position has no separate slider — click the detailed speaker image to move the mic from the cone center toward its edge. Gain, T-Comp, Bass, Middle, Treble, Presence and Effect Level all share one console-style fader board using the same layout as the Mixer EQ. A Play/Stop preview runs synthesized guitar chords through an approximate amp, cabinet and microphone chain; every setting changes the sound live. The artwork is original, brand-neutral UI bundled with the editor.
- **Track FX Edit window:** the Track FX tab uses the same Setup and Bank A–D cards as Input FX (Insert lists ALL or TRACK 1–6). Track FX effects open the same Edit window as Input FX (effect switcher, grouped cards, step sequencer and previews). The Track-only **Beat Scatter**, **Beat Repeat**, **Beat Shift** and **Vinyl Flick** have their own cards (pattern, direction, note-value Length / Shift, Slower ↔ Faster Flick) and a preview where the effect plays over a short drum, bass and melody track.
- **Step Tap controls:** the earlier Tap mode selector has been replaced by two direct buttons. While the sequence plays, **Tap On** (or T) restores the current step's previous level, and **Tap Off** (or Shift+T) sets it to zero.
- **Step preview defaults:** the sequencer opens with **Synth** selected and the **Metronome** off; both can still be changed from the transport.
- **Musical sequence controls:** below the Input FX step bars, **Rate** is a music-note scrub card that describes the selected division as Note, Dotted note, Triplet or Measures. **Step Max** uses the editor's existing count card and shows the active total as 1–16 Steps. Both support arrow buttons, mouse wheel, sideways drag and keyboard arrows.
- **Sequence and effect controls stay separate:** the dark sequencer contains only step-related controls, which vary with the effect. Step Slicer shows Rate and Step Max there; other stepped effects (Vibrato, Tremolo, filters…) show Sequence, Step Sync, Retrigger, **Target**, Step Rate and Step Max. **Target** lists only the parameters that effect's sequence can change (Vibrato: Depth, D.Level, E.Level), and a line above the bars says what the steps change and warns when Sequence is OFF. The preview follows the Target — on Vibrato, Depth makes a pitch wobble whose depth follows the steps at the effect's Rate; Ring Modulator, Phaser, Flanger and Tremolo play their own effect too, each with a matching reference sound selected by default. Note-based effect Rates are music-note scrub cards. Effect parameters stay below under **Effect controls**. For Step Slicer, **Depth**, **Comp Threshold** and **Comp Gain** are color-coded scrub cards in that separate section. They still shape the reference preview; this is an approximation, not the RC-600's exact audio algorithm.
- **All Start and All Stop track cards:** in Loop → Play, each track has an on/off card under the All Start and All Stop headings — a green play icon (All Start) or stop icon (All Stop) when the track is included, greyed out when it is left out. Clicking the card toggles the track.
- **Audio track cards:** the Audio tab shows Tracks 1–6 three per row (two or one on narrower screens). Each track has its own color; a glowing dot means the track has audio, while empty tracks are dimmed with a dashed outline. The WAV file name and size fit on one line. Instead of a slider, a waveform shows the track's progress: bars light up in the track color as it plays, and clicking or dragging on it jumps to that point (arrow keys also work). The bars follow the real audio once it has been loaded; before that a dimmed stand-in shape is shown. The current time and total length sit below it. One row of icon buttons holds Play (lit while the track plays), Pause (keeps the position), Stop (returns to the start), Playback (follows the track's own Playback setting: a green repeat icon for **Loop**, where the track repeats seamlessly, or an amber "repeat once" icon for **1 Shot**, where it plays once and stops; clicking it changes that same setting in the memory, also while the track plays), Import, Export and Clear; a playing track's card lights up. Above the cards, a transport bar controls every track at once: **Play all** (starts each track that has audio from its current position and stays lit while anything plays), **Pause all** (keeps each position) and **Stop all** (returns every track to the start), next to a status such as "2 of 4 playing".

### Known limitations

- The 3D model uses approximate geometry and photographs; controls and sockets have no individual meshes, hotspots or editor navigation yet.

- In the Audio tab, a track's waveform shows its real shape only after the WAV is loaded (the first Play or Play all). Until then, the bars are a dimmed stand-in and do not reflect the audio.
- The Auto Riff preview and phrase picture use 30 invented phrases, one per Phrase number: Boss does not publish the RC-600's own phrases, so the pedal plays different riffs.
- The Input FX step sequencer's preview sound only approximates what the steps shape (volume, filter, pitch, pan, vibrato, ring modulator, phaser, flanger, tremolo or isolator); Step Slicer step lengths are not heard in the preview.
- Parameters the Parameter Guide does not describe (such as Phaser **Mode** / **Bi-Phase**, Flanger **Mode** and Ring Mod **Mode**) are saved to the memory but do not change the preview. The preview's Step Sync treats one measure as the loop, since the real loop length lives on the pedal.
- The order of the sequence **Target** options follows the Parameter Guide's ★ list; it matches the default (first option) in the factory files, but the other values have not been confirmed on the pedal yet.
- Track FX Beat effects: the Beat Scatter patterns P1–P4 and the Vinyl Flick speeds in the preview are our interpretation (Boss does not describe them), and the order of the Length / Shift note values has not been confirmed on the pedal yet.
- Safari and Chrome on iOS do not expose Web MIDI; live pedal control needs Web MIDI Browser (or a desktop Chrome/Edge session).
- Rhythm Converter saves one rhythm with a single time signature (RC-600 Beats 2/4–7/4 and 5/8–15/8) and up to 9,999 notes; fills are saved as one bar. The RHYTHM.RC0 layout was worked out from BOSS RC Rhythm Converter and is not officially documented, so keep a backup of the drive. It does not set per-memory rhythm Tempo or Kit; set them on the pedal or in the Rhythm settings. The part suggestion is a starting point: songs without section markers, or with odd time signatures, usually need a few bars adjusted by hand. Browser playback (including RC-600 Kit Preview) uses General MIDI samples and synthesized drums, which only approximate the RC-600 kits; hearing the real RC-600 kit needs MIDI, and switching its kit needs a Rhythm Kit assign on the current memory.
- On the hosted site, a license key is required before the editor loads. The same gate is on locally when `RC600_REQUIRE_LICENSE=1` is set, so the activation page can be tried before a key is entered.

### Internal

- **Local license key:** a local development build has an **Issue key** button in the top bar. It asks for name, email, an optional location, and optional start and end dates. Empty dates create a key that never expires. The button is left out of the production build, and the hosted site answers the same request with “not found.”

Esses cards de estado ficam numa grade uniforme logo abaixo dos controles rápidos de Play Level e Pan, que ficam em primeiro. A seção Input da pista usa os mesmos cards para MIC 1/2, INST 1/2 L/R e Rhythm: microfone, guitarra ou metrônomo verde quando a entrada é gravada na pista, cinza apagado quando fica de fora. Em Loop → Play, Single Track Change e Speed Change alternam **Immediate** (raio) / **Loop End** (violeta), Sync Adjust alterna **Measure** / **Beat** (verde-limão), e Fade Time In, Fade Time Out e Loop Length viraram cards de rolagem: o valor muda com a roda do mouse, arrastando para o lado no celular ou pelas duas setas (Loop Length 0 mostra **Auto**). Em Loop → Rhythm, Genre, Pattern e Kit continuam como listas; Variation alterna **A** → **B** → **C** → **D**, Start Trig alterna Loop Start → Rec End → Before Loop, Stop Trig alterna Off → Loop Stop → Rec End, Intro Rec / Intro Play / Ending / Fill viraram cards liga/desliga, Variation Change alterna Measure / Loop End, e Beat é um card de rolagem (2/4 … 15/8).
- **Cards de Input → Setup:** Phantom (MIC 1/2) mostra **Off** ou **+48V** em âmbar; Gain (INST 1/2) alterna **INST** (guitarra) e **LINE** (violeta); Stereo Link (MIC, INST 1, INST 2) alterna **Off** e **Linked**. Em System → Input → Setup, Preference (MIC, INST 1, INST 2) alterna **Memory** e **System**. Clicar no card troca o valor. Input → EQ tem duas visões, escolhidas no seletor **EQ / Cards** (fica salvo). **EQ** é uma mesa no estilo console: Switch ON/OFF no topo e um fader vertical por parâmetro agrupado por banda (Lo Cut, Low, Lo Mid, Hi Mid, High, Hi Cut, Output); faders de ganho sobem ou descem a partir de 0 dB, faders de frequência/Q enchem de baixo para cima. Arrastar, roda do mouse ou setas mudam o fader, clique duplo volta ao padrão, e a mesa fica esmaecida com o EQ em bypass. **Cards** mostra o Switch como card liga/desliga e cada banda (Lo Cut, Lo Gain, Lo Mid Freq / Q / Gain, Hi Mid Freq / Q / Gain, High Gain, Hi Cut, Level) como card de rolagem em ordem do grave para o agudo — roda do mouse, arraste lateral ou setas; cards fora do padrão ficam destacados. Em Input → Dynamics, Comp e NS de cada entrada (MIC 1 Comp, MIC 1 NS, …, INST 2 NS) usam o mesmo medidor segmentado do Play Level — valor grande, barra que esquenta do verde ao laranja conforme o efeito fica mais forte, legenda Compressor / Noise Suppressor, dois por linha (MIC 1 Comp | MIC 1 NS, MIC 2 Comp | MIC 2 NS, INST 1 NS | INST 2 NS — as entradas INST não têm compressor), com ícone de microfone ou guitarra no título e ícone de compressão (Comp) ou portão (NS) ao lado do valor; Comp 0 aparece como **OFF**, e MIC 1/2 viram MIC quando estão em stereo link. Output → Setup usa os mesmos cards: Output Knob alterna **All** → **Master** (caixa de som) → **Phones** (fone) → **Off**; Stereo Link (MAIN, SUB 1, SUB 2) alterna **Off** / **Linked**; e em System, Preference (MAIN, SUB 1, SUB 2, PHONES, Rhythm, Master FX) alterna **Memory** / **System**. Output → Routing → Track mostra uma coluna por saída com cards liga/desliga Track 1–6 (play verde quando a pista vai para lá). Output → Routing → Input/Rhythm começa com Rhythm Out (**Output** caixa de som / **Loop** violeta), Input Thru (**Thru** microfone / **Muted** âmbar) e Phones Rhythm (fone **On** / **Off** apagado, oculto quando Phones Out está em Individual), depois uma linha por saída com cards de MIC, INST e Rhythm (microfone, guitarra ou metrônomo verde quando vão para lá, caixa de som mudo quando não vão). Output → Routing → Phones Out é um card que avança pelas saídas — **MAIN** (caixa de som verde), **SUB 1** (violeta), **SUB 2** (azul) — e **Individual** (fone rosa), que dá ao PHONES seu próprio roteamento. Output → EQ (canais MAIN, SUB 1, SUB 2) tem o mesmo seletor **EQ / Cards**, a mesma mesa de faders e os mesmos cards do Input → EQ; a escolha de visão é salva separadamente. Output → Master FX é uma linha com três colunas: primeiro o card Insert, depois Comp e Reverb como medidores segmentados com a mesma barra do verde ao laranja do Input → Dynamics. Cada clique no card Insert avança para a próxima saída — **MAIN** (caixa de som verde), **SUB 1** (violeta), **SUB 2** (azul) e por fim **Off** — mostrando L/R separados quando a saída não está em stereo link. Com o Insert em Off, Comp e Reverb somem, porque os efeitos ficam desligados.
- **Cards de Input FX → Setup:** Selected Bank alterna **A** → **B** → **C** → **D** a cada clique. Cada banco (A–D) tem seu grupo de três cards com cor própria, com o banco no topo e o ajuste embaixo: Switch (**On** / **Off** apagado), Mode (**Multi**, vários plays empilhados / **Single** em violeta, um play só) e FX Target, que alterna **A** → **D** para escolher o FX controlado pelo pedal de expressão. Passar um banco para Single continua desligando os outros FX daquele banco, para que só um fique ligado.
- **Cards de Input FX → Bank A–D:** as abas Bank A–D usam as mesmas cores de banco do Setup (A ciano, B índigo, C âmbar, D rosa). Dentro de um banco, cada FX tem sua cor no título e nos cards (FX A verde, FX B laranja, FX C roxo, FX D vermelho). Cada FX (A–D) de um banco é uma linha com três cards. **Switch** junta liga/desliga e Switch Mode num card só; cada clique avança **Off** (ícone de power apagado) → **Toggle** (verde, cada pisada liga/desliga o efeito) → **Moment** (âmbar, o efeito soa só enquanto o switch está pressionado) → volta para Off. **Insert** avança pelas entradas onde o efeito é aplicado — **ALL**, MIC e INST (aparecem como MIC / INST quando em stereo link) — e volta para ALL. **Effect** mostra o efeito carregado; clicar nele abre a biblioteca de efeitos, e **Edit** abre os parâmetros. A **Effect library** é uma janela grande: lista de categorias à esquerda com contagem, busca, filtro **All / Factory / My effects** e os presets como blocos coloridos por categoria, agrupados em My effects e Factory. Clicar num preset carrega o efeito e mantém a biblioteca aberta, com o bloco carregado destacado, para você testar vários em sequência. Um botão **Edit** ao lado do Close leva aos parâmetros do efeito atual, e a janela Edit tem um botão **Library** ao lado do Close dela. No topo aparece em qual banco/FX você está carregando e o efeito atual, e embaixo dá para salvar o efeito atual em My effects. A janela Edit também tem um botão **Effect** no topo que abre a janela **Choose effect**, para trocar o slot direto para qualquer efeito da RC-600, inclusive efeitos sem preset na biblioteca.
- **Capturar efeitos da pedaleira:** a **Effect library** do Input FX tem um botão **Capture from pedal**. Ele lê todas as memórias carregadas (a cópia ativa de cada uma), percorre os quatro bancos e os quatro FX e salva cada efeito configurado (com todos os ajustes e a sequência de steps) em **My effects**, igual ao Save to My effects. Cada um recebe o nome com o número da memória, o nome da memória e o slot de FX (ex.: "007 Funk Jam AB"). Slots em THRU são ignorados, e um efeito cujo tipo e ajustes já estão em My effects não é salvo de novo, então capturar outra vez só adiciona o que for novo.
- **Sequenciador de steps do Input FX:** efeitos que funcionam por steps (Step Slicer, Tremolo, Phaser, Flanger, filtros, efeitos de pitch e de pan com sequência) mostram um sequenciador no topo da janela **Edit**. Dezesseis barras definem o valor de cada step: arraste para cima ou para baixo para ajustar um, ou arraste para o lado para pintar vários de uma vez (as setas do teclado também funcionam). O quadrado embaixo de cada barra zera aquele step, e clicar de novo traz o valor anterior de volta. No Step Slicer os quadrados seguem a visão: Level, Length, ou dois quadrados por step no Both. **Random** gera um padrão novo no estilo escolhido em **Pattern** (Euclidean, Gate, Stutter, Accent, Chaos ou Any). Steps além do **Step Max** ficam esmaecidos. Um ícone de ajuda abre **About FX sequences**, a referência do Parameter Guide para os parâmetros da sequência. **Play** toca um som de referência pela sequência — um **Beat**, um **Tone** ou um arpejo **Synth** — no BPM que você escolher (começa no tempo da memória), com **Metronome** opcional, e o step atual acende. Enquanto toca, **Tap** (ou a tecla T) muda o step que está tocando, para você bater o ritmo. Um seletor ao lado escolhe o que o Tap faz: **Toggle** (liga o step se estiver em 0, senão zera), **On** (só liga, voltando ao valor anterior) ou **Off** (só zera). A prévia só ilustra a sequência no navegador; não é o efeito real da RC-600. Toda mudança é gravada na memória como qualquer outro parâmetro. Os ajustes da sequência (Rate, Step Max e, nos efeitos com sequência, Sequence, Step Sync, Retrigger e Mode) ficam logo abaixo das barras. O Step Slicer tem um seletor **Level / Length / Both**: as barras de Level definem o volume de cada step, as de Length quanto tempo cada step soa antes de ser cortado (baixo = fatias curtas e picotadas; alto = o som preenche o step inteiro), e Both mostra as duas barras lado a lado em cada step — Level na cor do FX, Length em ciano; Depth, Comp Threshold e Comp Gain ficam abaixo do sequenciador.
- **Editor visual de Preamp:** a janela Edit do Preamp em Input FX começa com Amp Type, Speaker Type e o simulador de falante/microfone lado a lado (empilhados no mobile). Deslize a imagem de Amp/Speaker para a esquerda/direita ou toque em qualquer ponto das faixas laterais com altura total para avançar entre as opções; as setas continuam discretas e não há trilho adicional de slider. No simulador, a cena da caixa fica à esquerda e uma lista vertical à direita mostra todos os Mic Types; clicar em um microfone aplica esse modelo na hora. Mic Distance usa o controle padrão de duas opções. A representação visual de perto/longe é demonstrativa e mantém o microfone visível, enquanto o valor exato salvo continua sendo enviado à pedaleira. Mic Position não tem slider separado — clique na imagem detalhada do falante para mover o microfone do centro do cone até a borda. Gain, T-Comp, Bass, Middle, Treble, Presence e Effect Level dividem uma única mesa de faders com o mesmo layout do EQ do Mixer. Uma prévia Play/Stop passa acordes de guitarra sintetizada por uma cadeia aproximada de amplificador, caixa e microfone; todos os ajustes mudam o som ao vivo. As ilustrações são originais, sem marcas e vêm no próprio editor.
- **Janela Edit do Track FX:** a aba Track FX usa os mesmos cards de Setup e Bancos A–D do Input FX (o Insert lista ALL ou TRACK 1–6). Os efeitos do Track FX abrem a mesma janela Edit do Input FX (troca de efeito, cards agrupados, sequenciador de steps e prévias). Os exclusivos de pista **Beat Scatter**, **Beat Repeat**, **Beat Shift** e **Vinyl Flick** têm cards próprios (padrão, direção, Length / Shift em valores de nota, Flick Slower ↔ Faster) e uma prévia em que o efeito toca sobre uma pista curta de bateria, baixo e melodia.
- **Controles Tap dos steps:** o seletor anterior de modo do Tap foi substituído por dois botões diretos. Enquanto a sequência toca, **Tap On** (ou T) recupera o nível anterior do step atual, e **Tap Off** (ou Shift+T) zera o step.
- **Padrões da prévia de steps:** o sequenciador abre com **Synth** selecionado e o **Metronome** desligado; os dois continuam configuráveis no transporte.
- **Controles musicais da sequência:** abaixo das barras do Input FX, **Rate** é um card de rolagem com nota musical que descreve a divisão escolhida como Note, Dotted note, Triplet ou Measures. **Step Max** usa o card de contagem já existente no editor e mostra o total ativo como 1–16 Steps. Os dois aceitam setas, roda do mouse, arraste lateral e setas do teclado.
- **Controles de sequência e efeito separados:** o sequenciador escuro contém apenas os controles relacionados aos steps, que variam conforme o efeito. O Step Slicer mostra Rate e Step Max ali; outros efeitos com steps (Vibrato, Tremolo, filtros…) mostram Sequence, Step Sync, Retrigger, **Target**, Step Rate e Step Max. O **Target** lista só os parâmetros que a sequência daquele efeito pode mudar (Vibrato: Depth, D.Level, E.Level), e uma linha acima das barras diz o que os steps mudam e avisa quando o Sequence está OFF. A prévia segue o Target — no Vibrato, Depth faz uma oscilação de afinação cuja profundidade segue os steps, no Rate do efeito; o Ring Modulator, o Phaser, o Flanger e o Tremolo também tocam o próprio efeito, cada um com um som de referência próprio já selecionado. Os Rates de efeito baseados em notas viram cards de nota musical. Os parâmetros do efeito ficam abaixo em **Effect controls**. No Step Slicer, **Depth**, **Comp Threshold** e **Comp Gain** são cards de rolagem coloridos nessa seção separada. Eles ainda moldam a prévia de referência; é uma aproximação, não o algoritmo de áudio exato da RC-600.
- **Cards de pistas All Start e All Stop:** em Loop → Play, cada pista tem um card liga/desliga sob os títulos All Start e All Stop — ícone verde de play (All Start) ou de stop (All Stop) quando a pista está incluída, apagado quando fica de fora. Clicar no card alterna a pista.
- **Cards de pistas em Audio:** a aba Audio mostra as Tracks 1–6 em três por linha (duas ou uma em telas mais estreitas). Cada pista tem sua cor; um ponto aceso indica que a pista tem áudio, e pistas vazias ficam apagadas com contorno tracejado. O nome e o tamanho do arquivo WAV cabem em uma linha. No lugar do slider, uma forma de onda mostra o andamento da pista: as barras acendem na cor da pista conforme ela toca, e clicar ou arrastar sobre ela pula para aquele ponto (as setas do teclado também funcionam). As barras seguem o áudio real depois que ele é carregado; antes disso aparece uma forma provisória esmaecida. O tempo atual e a duração total ficam logo abaixo. Uma linha de botões com ícones reúne Play (aceso enquanto a pista toca), Pause (mantém a posição), Stop (volta ao início), Playback (segue a configuração Playback da própria pista: ícone verde de repetição para **Loop**, em que a pista se repete sem emenda, ou ícone âmbar de "repetir uma vez" para **1 Shot**, em que ela toca uma vez e para; clicar muda essa mesma configuração na memória, inclusive com a pista tocando), Import, Export e Clear; o card da pista que está tocando fica iluminado. Acima dos cards, uma barra de transporte controla todas as pistas de uma vez: **Play all** (toca cada pista com áudio a partir da posição atual e fica aceso enquanto algo toca), **Pause all** (mantém cada posição) e **Stop all** (volta todas as pistas ao início), ao lado de um status como "2 of 4 playing".

### Limitações conhecidas

- A prévia e o desenho de frase do Auto Riff usam 30 frases inventadas, uma por número de Phrase: a Boss não publica as frases da RC-600, então a pedaleira toca riffs diferentes.
- O modelo 3D usa geometria aproximada e fotografias; controles e conectores ainda não possuem malhas individuais, hotspots ou navegação para o editor.

- Na aba Audio, a forma de onda de uma pista só mostra o formato real depois que o WAV é carregado (no primeiro Play ou Play all). Até lá, as barras são uma forma provisória esmaecida e não refletem o áudio.
- O som da prévia do sequenciador de steps do Input FX só aproxima o que os steps moldam (volume, filtro, pitch, pan, vibrato, ring modulator, phaser, flanger, tremolo ou isolator); o comprimento dos steps do Step Slicer não aparece na prévia.
- Parâmetros que o Parameter Guide não descreve (como **Mode** / **Bi-Phase** do Phaser, **Mode** do Flanger e **Mode** do Ring Mod) são salvos na memória, mas não mudam a prévia. O Step Sync da prévia considera um compasso como o loop, já que o tamanho real do loop fica na pedaleira.
- A ordem das opções do **Target** da sequência segue a lista ★ do Parameter Guide; ela bate com o padrão (primeira opção) dos arquivos de fábrica, mas os outros valores ainda não foram confirmados no pedal.
- Efeitos Beat do Track FX: os padrões P1–P4 do Beat Scatter e as velocidades do Vinyl Flick na prévia são uma interpretação nossa (a Boss não os descreve), e a ordem dos valores de nota de Length / Shift ainda não foi confirmada no pedal.
- Safari e Chrome no iOS não expõem Web MIDI; o controle ao vivo do pedal exige o Web MIDI Browser (ou Chrome/Edge no computador).
- O Rhythm Converter grava um ritmo com uma única fórmula de compasso (Beats da RC-600 de 2/4–7/4 e 5/8–15/8) e até 9.999 notas; as viradas são gravadas com um compasso. O formato do RHYTHM.RC0 foi deduzido do BOSS RC Rhythm Converter e não tem documentação oficial, então mantenha um backup do drive. Ele não define Tempo nem Kit do ritmo em cada memória; ajuste na pedaleira ou nas configurações de Rhythm. A sugestão de partes é um ponto de partida: músicas sem marcações de seção, ou com fórmulas de compasso incomuns, costumam precisar de alguns compassos ajustados à mão. A reprodução no navegador (inclusive o RC-600 Kit Preview) usa samples General MIDI e baterias sintetizadas, que só se aproximam dos kits da RC-600; ouvir o kit real da RC-600 exige MIDI, e trocar o kit exige um assign de Rhythm Kit na memória atual.
- No site hospedado, a chave de licença é exigida antes de o editor carregar. A mesma trava vale no local quando `RC600_REQUIRE_LICENSE=1` está ligado, para testar a tela de ativação antes de informar a chave.

### Interno

- **Chave local:** o build de desenvolvimento local tem o botão **Issue key** na barra de cima. Ele pede nome, e-mail, local opcional e datas opcionais de início e fim. Sem datas, a chave não expira. O botão fica de fora do build de produção, e o site hospedado responde o mesmo pedido com “não encontrado”.
