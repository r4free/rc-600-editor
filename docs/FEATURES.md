# RC-600 Editor — Feature registry / Registro de funcionalidades

**Version:** pre-release · **Updated:** 2026-10-03

Shared ritual: https://github.com/r4free/boss-editor-guidelines (`shared/feature-registry.mdc`).

## EN

### Shipped

- **Navigation breadcrumb:** the path above the workspace content follows the currently visible tabs, including nested tracks, routing and EQ channels. Earlier levels return focus to that level's tabs without resetting edits or changing the pedal.
- **3D Model panel:** next to Chain, open a photo-textured RC-600 model with rotation, keyboard controls, zoom, panel and rear views. This first integration is visual only.

- **Paid activation:** on the hosted site, a welcoming first screen introduces the editor's memory, backup/MIDI, and performance tools; returning users can enter a license key, while new users can open Stripe Checkout or explore the user guide. The key is sent by email after payment. The editor pages and scripts stay on the server until that key is accepted. Local development still opens the editor without a key.
- **User guide:** the Guide link opens an English beginner walkthrough in a new tab, with real editor screenshots, all main tabs and sub-tabs, file/MIDI workflows, troubleshooting, light/dark themes and browser printing to PDF.
- Memory / looper oriented web editor for the Boss RC-600.
- Horizontal editor tabs and English-only UI (see Cursor rules).
- Links to sibling VG / GM / GT / TONEX editors.
- On iPhone/iPad browsers without Web MIDI, a dismissible warning recommends opening the site in **Web MIDI Browser** (App Store), and MIDI Connect is enabled when that API is present.
- **Setlists:** live charts, score guides, and setlist editing are part of the editor. On the hosted site they open with the same license key as the rest of the app. Setlists already saved in this browser stay in this browser.
- **Keep playing** on alphaTab scores (opt-in): audio keeps going after you close the live viewer or leave Setlists. A floating mini-player shows the song on any screen and restores the viewer; the toggle is remembered in this browser. Stop, turning Keep playing off, or the end of the piece clears the session (playback itself does not resume after a full page reload).
- **Comfortable dark interface:** clearer headings and parameter groups, roomier controls, softer panels, consistent keyboard focus and selection states, and a prominent unsaved-changes indicator make the existing editor easier to scan without changing its navigation or workflows.
- **Quick volume controls:** track, mixer, and effect volume parameters move to the top of their group and use a compact segmented slider. Active bars graduate through green up to 100, then orange, red, and dark red above 100.
- **Centered pan controls:** track and effect pan parameters use a compact segmented slider whose tall ends and low center make the stereo position immediately visible. When Volume and Pan share a group, they form a two-column quick-control header.
- **Track playback direction card:** in Loop → Tracks, Reverse is shown as a compact Direction card next to Play Level and Pan. A green arrow spinning clockwise means the track plays **Forward**; a red arrow spinning counter-clockwise means it plays in **Reverse**. Clicking the card switches direction. 1 Shot works the same way in a Playback card: a green repeat icon for **Loop**, or an amber "repeat once" icon for **1 Shot**. Bounce In appears as a Rec Source card: a green microphone for **Input** (inputs only) or a violet merge icon for **Bounce** (inputs plus other tracks' playback). Loop Sync appears as a card showing **Synced** (green link) or, highlighted in amber, **Free** (broken link). Loop Sync Mode has three values, so each click steps Immediate → Measure → Loop Length: a fuchsia lightning bolt for **Immediate** (starts when you press the switch), a lime ruler for **Measure** (waits for the next measure) and a green repeat icon for **Loop Length** (follows the LOOP LENGTH setting). Tempo Sync shows **Memory** (green metronome) or, highlighted in pink, **Original** (recording tempo). FX shows **Wet** (green waveform, Input FX / Track FX applied) or, highlighted in orange, **Dry** (bypassed). Start Mode shows **Immediate** (green play icon) or, highlighted in yellow, **Fade** (rising ramp). Play Mode shows **Multi** (green stacked play boxes) or, highlighted in indigo, **Single** (one play box). Tempo Sync Mode appears as a Tempo Sync Mode card: **XFade** (green swap arrows, keeps pitch) or, highlighted in rose, **Pitch** (music note, pitch follows tempo). Tempo Sync Speed has three values, so each click steps Half → Normal → Double: a blue slow gauge for **Half**, green for **Normal**, an orange fast gauge for **Double**. Stop Mode steps the same way through **Immediate** (green stop icon), **Fade** (yellow falling ramp) and **Loop End** (purple arrow to the end). Dub Mode steps through **Overdub** (green layers icon, new material on top), **Replace 1** (red replace icon) and **Replace 2** (orange replace icon); both Replace values overwrite the existing take while you record. Measure cycles Auto → Free → a measure count that you scrub with the wheel, a sideways drag or arrows; clicking the number returns to Auto. Loop → Record uses the same cards for Rec Play Action, Quantize, Auto Rec, Bounce and Bounce Track 1–6. These state cards sit in an evenly spaced grid right below the Play Level and Pan quick controls, which stay first. The track's Input section uses the same cards for MIC 1/2, INST 1/2 L/R and Rhythm: a green microphone, guitar or metronome when the input is recorded onto the track, dimmed grey when it is left out. In Loop → Play, Single Track Change and Speed Change toggle **Immediate** (lightning bolt) / **Loop End** (violet), Sync Adjust toggles **Measure** / **Beat** (lime), and Fade Time In, Fade Time Out and Loop Length are scrub cards: change the value with the mouse wheel, a sideways drag on touch screens or the two arrows (Loop Length 0 shows **Auto**). In Loop → Rhythm, Genre, Pattern and Kit stay as lists; Variation cycles **A** → **B** → **C** → **D**, Start Trig cycles Loop Start → Rec End → Before Loop, Stop Trig cycles Off → Loop Stop → Rec End, Intro Rec / Intro Play / Ending / Fill are on/off cards, Variation Change toggles Measure / Loop End, and Beat is a scrub card (2/4 … 15/8).
- **Input → Setup cards:** Phantom (MIC 1/2) shows **Off** or amber **+48V**; Gain (INST 1/2) toggles **INST** (guitar) and **LINE** (violet); Stereo Link (MIC, INST 1, INST 2) toggles **Off** and **Linked**. In System → Input → Setup, Preference (MIC, INST 1, INST 2) toggles **Memory** and **System**. Clicking the card switches the value. Input → EQ has two views, chosen with the **EQ / Cards** toggle (remembered). **EQ** is a console-style board: an ON/OFF Switch on top and one vertical fader per parameter grouped by band (Lo Cut, Low, Lo Mid, Hi Mid, High, Hi Cut, Output); gain faders grow up or down from 0 dB, frequency/Q faders fill from the bottom. Drag, mouse wheel or arrow keys change a fader, double-click resets it, and the board dims while the EQ is bypassed. **Cards** shows Switch as an on/off card and every band (Lo Cut, Lo Gain, Lo Mid Freq / Q / Gain, Hi Mid Freq / Q / Gain, High Gain, Hi Cut, Level) as a scrub card ordered from low to high — mouse wheel, sideways drag or arrows; cards differing from the default are highlighted. In Input → Dynamics, Comp and NS for each jack (MIC 1 Comp, MIC 1 NS, …, INST 2 NS) use the same segmented meter as Play Level — big value, bar that warms from green to orange as the effect gets heavier, Compressor / Noise Suppressor caption, laid out two per row (MIC 1 Comp | MIC 1 NS, MIC 2 Comp | MIC 2 NS, INST 1 NS | INST 2 NS — INST jacks have no compressor) with a microphone or guitar icon on the label and a squeeze (Comp) or gate (NS) icon by the value; Comp 0 reads **OFF**, and MIC 1/2 merge into MIC when stereo-linked. Output → Setup uses the same cards: Output Knob cycles **All** → **Master** (speaker) → **Phones** (headphones) → **Off**; Stereo Link (MAIN, SUB 1, SUB 2) toggles **Off** / **Linked**; and in System, Preference (MAIN, SUB 1, SUB 2, PHONES, Rhythm, Master FX) toggles **Memory** / **System**.
- **All Start and All Stop track cards:** in Loop → Play, each track has an on/off card under the All Start and All Stop headings — a green play icon (All Start) or stop icon (All Stop) when the track is included, greyed out when it is left out. Clicking the card toggles the track.

### Partial

- Expand this registry as user-visible capabilities ship.

### Known limitations

- The 3D model uses approximate geometry and photographs; controls and sockets have no individual meshes, hotspots or editor navigation yet.

- Safari and Chrome on iOS do not expose Web MIDI; live pedal control needs Web MIDI Browser (or a desktop Chrome/Edge session).
- On the hosted site, a license key is required before the editor loads. The same gate is on locally when `RC600_REQUIRE_LICENSE=1` is set, so the activation page can be tried before a key is entered.

## PT

### Entregue

- **Breadcrumb de navegação:** o caminho acima do conteúdo acompanha as abas visíveis, incluindo pistas, roteamento e canais EQ aninhados. Níveis anteriores devolvem o foco às abas daquele nível sem reiniciar a edição nem alterar a pedaleira.
- **Painel 3D Model:** ao lado de Chain, abre um modelo da RC-600 com fotos como texturas, rotação, controles por teclado, zoom e vistas do painel e da traseira. Esta primeira integração é apenas visual.

- **Ativação paga:** no site hospedado, uma tela inicial mais acolhedora apresenta os recursos de memórias, backup/MIDI e performance do editor; quem já comprou informa a chave, enquanto novos usuários podem abrir o Stripe Checkout ou conhecer o guia. A chave é enviada por e-mail depois do pagamento. Páginas e scripts do editor ficam no servidor até a chave ser aceita. No desenvolvimento local, o editor ainda abre sem chave.
- **Guia de uso:** o link Guide abre em nova aba um passo a passo em inglês para iniciantes, com capturas reais do editor, abas e subabas, fluxos de arquivos/MIDI, solução de problemas, temas claro/escuro e impressão em PDF pelo navegador.
- Editor web orientado a memória / looper para o Boss RC-600.
- Abas horizontais e UI só em inglês (ver Cursor rules).
- Links para os editores irmãos VG / GM / GT / TONEX.
- Em iPhone/iPad sem Web MIDI, um aviso dispensável recomenda abrir o site no **Web MIDI Browser** (App Store), e o Connect MIDI é liberado quando essa API existe.
- **Setlists:** charts ao vivo, partituras e edição de setlist fazem parte do editor. No site hospedado eles abrem com a mesma chave de licença do restante do aplicativo. Setlists já salvos neste navegador continuam neste navegador.
- **Keep playing** nas partituras alphaTab (opcional): o áudio continua depois de fechar a view ao vivo ou sair de Setlists. Um mini-player flutuante mostra a música em qualquer tela e restaura o viewer; o toggle fica lembrado neste navegador. Stop, desligar Keep playing ou o fim da peça limpam a sessão (a reprodução em si não retoma após um reload completo).
- **Interface escura mais confortável:** títulos e grupos de parâmetros mais claros, controles mais espaçosos, painéis mais suaves, estados consistentes de foco e seleção por teclado e um indicador destacado de alterações não salvas facilitam explorar o editor sem mudar sua navegação ou seus fluxos.
- **Controles rápidos de volume:** parâmetros de volume de pistas, mixer e efeitos aparecem primeiro no grupo com slider segmentado compacto. As barras ativas passam em degradê por verde até 100 e depois por laranja, vermelho e vermelho escuro acima de 100.
- **Controles de pan centralizados:** parâmetros de pan de pistas e efeitos usam um slider segmentado compacto, com pontas altas e centro baixo para mostrar imediatamente a posição estéreo. Quando Volume e Pan estão no mesmo grupo, eles formam um cabeçalho de controles rápidos em duas colunas.
- **Card de direção de reprodução da pista:** em Loop → Tracks, o Reverse aparece como um card compacto Direction ao lado de Play Level e Pan. Uma seta verde girando no sentido horário indica que a pista toca em **Forward**; uma seta vermelha girando no sentido anti-horário indica **Reverse**. Clicar no card troca a direção. O 1 Shot funciona do mesmo jeito em um card Playback: ícone verde de repetição para **Loop** ou ícone âmbar de "repetir uma vez" para **1 Shot**. O Bounce In aparece como card Rec Source: microfone verde para **Input** (só as entradas) ou ícone violeta de junção para **Bounce** (entradas mais o playback das outras pistas). O Loop Sync aparece como card mostrando **Synced** (link verde) ou, destacado em âmbar, **Free** (link cortado). O Loop Sync Mode tem três valores, então cada clique avança Immediate → Measure → Loop Length: raio fúcsia para **Immediate** (começa quando você pisa no switch), régua verde-limão para **Measure** (espera o próximo compasso) e ícone verde de repetição para **Loop Length** (segue o ajuste LOOP LENGTH). O Tempo Sync mostra **Memory** (metrônomo verde) ou, destacado em rosa, **Original** (tempo da gravação). O FX mostra **Wet** (waveform verde, Input FX / Track FX aplicados) ou, destacado em laranja, **Dry** (efeitos desviados). O Start Mode mostra **Immediate** (play verde) ou, destacado em amarelo, **Fade** (rampa subindo). O Play Mode mostra **Multi** (vários plays empilhados em verde) ou, destacado em índigo, **Single** (um play só). O Tempo Sync Mode aparece como card Tempo Sync Mode: **XFade** (setas de troca em verde, mantém a afinação) ou, destacado em rosa-coral, **Pitch** (nota musical, a afinação acompanha o tempo). O Tempo Sync Speed tem três valores, então cada clique avança Half → Normal → Double: velocímetro lento azul para **Half**, verde para **Normal** e velocímetro rápido laranja para **Double**. O Stop Mode avança do mesmo jeito por **Immediate** (stop verde), **Fade** (rampa descendo em amarelo) e **Loop End** (seta roxa até o fim). O Dub Mode avança por **Overdub** (ícone de camadas verde, material novo por cima), **Replace 1** (ícone de substituir em vermelho) e **Replace 2** (ícone de substituir em laranja); os dois Replace sobrescrevem a tomada existente enquanto você grava. O Measure alterna Auto → Free → número de compassos, ajustado com a rodinha, arrastando para o lado ou pelas setinhas; clicar no número volta para Auto. Loop → Record usa os mesmos cards para Rec Play Action, Quantize, Auto Rec, Bounce e Bounce Track 1–6. Esses cards de estado ficam numa grade uniforme logo abaixo dos controles rápidos de Play Level e Pan, que ficam em primeiro. A seção Input da pista usa os mesmos cards para MIC 1/2, INST 1/2 L/R e Rhythm: microfone, guitarra ou metrônomo verde quando a entrada é gravada na pista, cinza apagado quando fica de fora. Em Loop → Play, Single Track Change e Speed Change alternam **Immediate** (raio) / **Loop End** (violeta), Sync Adjust alterna **Measure** / **Beat** (verde-limão), e Fade Time In, Fade Time Out e Loop Length viraram cards de rolagem: o valor muda com a roda do mouse, arrastando para o lado no celular ou pelas duas setas (Loop Length 0 mostra **Auto**). Em Loop → Rhythm, Genre, Pattern e Kit continuam como listas; Variation alterna **A** → **B** → **C** → **D**, Start Trig alterna Loop Start → Rec End → Before Loop, Stop Trig alterna Off → Loop Stop → Rec End, Intro Rec / Intro Play / Ending / Fill viraram cards liga/desliga, Variation Change alterna Measure / Loop End, e Beat é um card de rolagem (2/4 … 15/8).
- **Cards de Input → Setup:** Phantom (MIC 1/2) mostra **Off** ou **+48V** em âmbar; Gain (INST 1/2) alterna **INST** (guitarra) e **LINE** (violeta); Stereo Link (MIC, INST 1, INST 2) alterna **Off** e **Linked**. Em System → Input → Setup, Preference (MIC, INST 1, INST 2) alterna **Memory** e **System**. Clicar no card troca o valor. Input → EQ tem duas visões, escolhidas no seletor **EQ / Cards** (fica salvo). **EQ** é uma mesa no estilo console: Switch ON/OFF no topo e um fader vertical por parâmetro agrupado por banda (Lo Cut, Low, Lo Mid, Hi Mid, High, Hi Cut, Output); faders de ganho sobem ou descem a partir de 0 dB, faders de frequência/Q enchem de baixo para cima. Arrastar, roda do mouse ou setas mudam o fader, clique duplo volta ao padrão, e a mesa fica esmaecida com o EQ em bypass. **Cards** mostra o Switch como card liga/desliga e cada banda (Lo Cut, Lo Gain, Lo Mid Freq / Q / Gain, Hi Mid Freq / Q / Gain, High Gain, Hi Cut, Level) como card de rolagem em ordem do grave para o agudo — roda do mouse, arraste lateral ou setas; cards fora do padrão ficam destacados. Em Input → Dynamics, Comp e NS de cada entrada (MIC 1 Comp, MIC 1 NS, …, INST 2 NS) usam o mesmo medidor segmentado do Play Level — valor grande, barra que esquenta do verde ao laranja conforme o efeito fica mais forte, legenda Compressor / Noise Suppressor, dois por linha (MIC 1 Comp | MIC 1 NS, MIC 2 Comp | MIC 2 NS, INST 1 NS | INST 2 NS — as entradas INST não têm compressor), com ícone de microfone ou guitarra no título e ícone de compressão (Comp) ou portão (NS) ao lado do valor; Comp 0 aparece como **OFF**, e MIC 1/2 viram MIC quando estão em stereo link. Output → Setup usa os mesmos cards: Output Knob alterna **All** → **Master** (caixa de som) → **Phones** (fone) → **Off**; Stereo Link (MAIN, SUB 1, SUB 2) alterna **Off** / **Linked**; e em System, Preference (MAIN, SUB 1, SUB 2, PHONES, Rhythm, Master FX) alterna **Memory** / **System**.
- **Cards de pistas All Start e All Stop:** em Loop → Play, cada pista tem um card liga/desliga sob os títulos All Start e All Stop — ícone verde de play (All Start) ou de stop (All Stop) quando a pista está incluída, apagado quando fica de fora. Clicar no card alterna a pista.

- Expandir este registro conforme capacidades visíveis forem lançadas.

### Limitações conhecidas

- O modelo 3D usa geometria aproximada e fotografias; controles e conectores ainda não possuem malhas individuais, hotspots ou navegação para o editor.

- Safari e Chrome no iOS não expõem Web MIDI; o controle ao vivo do pedal exige o Web MIDI Browser (ou Chrome/Edge no computador).
- No site hospedado, a chave de licença é exigida antes de o editor carregar. A mesma trava vale no local quando `RC600_REQUIRE_LICENSE=1` está ligado, para testar a tela de ativação antes de informar a chave.
